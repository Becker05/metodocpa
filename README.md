# Método CPA — Pitch de infraestrutura de dados

Landing page do pitch comercial de diagnóstico e implementação de tracking para e-commerce (captura, persistência, ativação de sinais). Página estática única, sem dependências de build.

## Publicar no GitHub Pages

1. Crie um repositório novo (ex.: `pitch-cpa`) e suba estes arquivos na raiz.
2. Em **Settings → Pages**, defina **Source: Deploy from a branch**, branch `main`, pasta `/root`.
3. A página fica em `https://<seu-usuario>.github.io/pitch-cpa/`.

## Arquivos

- `index.html` — página completa (HTML, CSS e JS inline)
- `.nojekyll` — evita o processamento Jekyll do Pages

## Editar

Todo o conteúdo (preço, prazos, itens de entrega) está no `index.html`. Cores no bloco `:root`.
